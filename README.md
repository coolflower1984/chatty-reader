# 十词一组 · ChattyReader

安卓端的六级词汇精读工具。**装好即用，全程离线**：内置 Unit 1–10 的文字和录音，打开就能听；剩下 230 个单元按「十个一组」做成更新包，在 App 里点一下就下，下哪个装哪个。

早期那套「开梯子 → 刷 X → 发给 ChatGPT」的流程还在，但收进了首页最下方的折叠区，当备用入口。

> 当前版本 **v4.5**（versionCode 20）· minSdk 26 · targetSdk 35 · Kotlin + Jetpack Compose

---

## 一、一个单元里有什么

10 个词（少数单元只有 2–5 个，词书分组末尾本来就这样），每个词三段：

1. **猜一猜**：两三句 A2 水平的简单英语，把这个词放进具体场景，结尾一句提问，音频末尾留 3 秒空白给你想
2. **释义**：纯英文解释，句式是 `X is...` / `To X is to...`，并回扣上面那个场景
3. **六级语境**：45 词左右的学术段落（经济、政策、科研、社会议题），带一个常见搭配

十个词讲完，是一篇 **165–190 词的阅读**，把本单元的词全部串进同一个故事；后面 **5 道选择题**，题干按六级阅读的常见问法写，点完选项立刻出中文解析，并点名最强干扰项错在哪（偷换概念、以偏概全、无中生有）。

### 声音

- 奇数词、阅读全文：**英音女声**（en-GB-SoniaNeural）
- 偶数词、题目：**美音男声**（en-US-AndrewNeural）

两把声音交替，十个词听下来不腻，也顺便让你习惯两种口音。每段能单独重播，一个词也能「连播」三段。

## 三、240 个单元怎么装进手机

每单元音频约 **10 分钟 / 3.5 MB**。240 个单元全量约 **820 MB**，塞不进安装包，重新打包上传也不现实。

所以拆成 **23 个更新包（Unit 11–240），每个 10 个单元、约 35 MB**：

| | 包体 | 内容 |
|---|---|---|
| 安装包 | 约 44 MB | Unit 1–10 的文字 + 音频，开箱即用 |
| 更新包 × 23 | 每个约 35 MB | Unit 11–240，App 内下载导入 |

装完 App 后，用哪个单元就下哪个包，导入后永久离线可用。装了 3 个包约占 105 MB，而不是一次吃掉 820 MB。

导入会做三件事：解压到临时目录（中途失败不留半套内容）→ 校验 10 个 JSON 和每个单元该有的音频一个不少（少一个就整包拒绝）→ 全部通过才原子合并到 `filesDir/content`。包里所有路径都做了 `..` 检查，写不出应用目录。

## 四、内容是怎么来的

不是手写，也不是每次现问模型，而是一条可复现的流水线：

```
词表(vocab.json) → 单元 JSON（人工审校）→ 校验 → Edge TTS 合成 → ffmpeg 补静音 → 打包
```

- `words/uNNN.txt`：240 份词表，从原始 30 份 docx 抽取
- `uNNN.json`：单元正文，字段与范本完全一致
- `validate.py`：结构校验（字段齐全、音标与释义与词表逐字一致、reading 词数、每个词是否都出现、答案分布、中文是否混进英文段）
- `build_audio.py`：按奇数/偶数分配音色，一批 10–20 个单元并行合成，猜词段补 3 秒、题目补 4 秒静音
- `build_pack.py`：打成 zip，写 manifest，输出 md5

校验脚本报 0 错误才继续合成音频 —— 先改文字比先改音频便宜一个数量级。词形变化（`cling → clung`、`defy → defied`、`sip → sipping`）都放行，但真的没出现的词会报错。

## 五、从源码构建

需要 JDK 17 与 Android SDK（compileSdk 35）。

```bash
git clone https://github.com/coolflower1984/chatty-reader.git
cd chatty-reader
./gradlew assembleDebug          # 产物：app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # 45 条单元测试
```

`local.properties` 里写 `sdk.dir=/path/to/android-sdk`（该文件已在 `.gitignore` 中）。

仓库内的 `releases/chatty-reader-v4.5.apk` 是可直接安装的成品包，也可以从 [Releases](https://github.com/coolflower1984/chatty-reader/releases) 页下载同一份。

## 六、安装

- **覆盖安装，不要先卸载**，否则已授予的权限会清空
- 首次装要允许「安装未知应用」，Chrome 会提示「此类文件可能有害」，选「仍要下载」
- App 内更新走同样的覆盖安装，更新包在「内置教材 → 资源管理」里下载

app/src/main/java/com/chatty/reader/
├── MainActivity.kt              页面路由与返回键

├── study/

│   ├── ContentRepo.kt           更新包导入、外部内容目录、音频查找

│   ├── UpdateRepo.kt            manifest 拉取、更新包下载、generation 护栏
│   ├── ApkUpdate.kt             版本比较、跳过此版本、调起安装
│   ├── StudyProgress.kt         已学词集合、上次位置、单单元/全量重置
│   └── VocabBook.kt             生词本落盘（JSON）
├── ui/
│   ├── HomeScreen.kt            首页：继续学习卡 + 内置教材入口 + 折叠的旧流程

│   ├── VocabScreen.kt           生词本列表
│   ├── SelectionMenu.kt         长按选中的操作条
│   ├── UpdateDialog.kt          发现新版本的弹窗
│   ├── SettingsScreen.kt        权限、时长、固定要求
│   └── Sheets.kt                词库选择、发送预览
├── share/AskAi.kt               定向 DeepSeek 的提示词与跳转
├── watch/                       旧流程：前台监听、状态机、超级岛
├── vocab/                       词库与提示词拼接
└── launch/                      应用跳转、系统授权
app/src/main/assets/
├── units/u001..u010.json        单元正文

## 八、已知限制

- **部分单元只有 2–5 个词**，来自词书分组末尾，不是漏抓
- 音频是 48 kbps 单声道 mp3，人声够用，音乐性为零 —— 换 opus 能再省四成，但部分老机型解码不稳
- 内置教材**不做复习计划**：只记「学过没学过」，不记对错、不排艾宾浩斯
- 删除下载的单元要**长按那一行**，普通点击是打开；内置的 10 个删不掉
- 旧流程依赖「使用情况访问」权限，小米机型上偶尔会被系统回收，回设置页重新给一次即可
- App 内的更新与下载指向作者自己的静态站点，仓库里留着 `sharecode`，换个环境部署需自行改 `UpdateRepo.kt` 里的 `BASE` / `SHARE`
